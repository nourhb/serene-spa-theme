# Serene — Spa & Wellness Block Theme

**Serene** is a calming WordPress block theme built for spas, wellness centers and beauty retreats. Soft sage tones, airy serif typography, treatment menus, therapist profiles and booking-ready patterns — a tranquil digital retreat for your sanctuary.

## Features

- **Full Site Editing** — edit headers, footers, templates and every pixel with the block editor
- **Complete theme.json design system** — sage/eucalyptus/cream/stone/gold palette, Cormorant Garamond display + Jost body type, fluid type scale, soft shadows
- **10 hand-built block patterns** — spa hero, sanctuary story, treatment menu, wellness packages, therapists team, photo gallery, guest testimonials, animated stats band, booking CTA, spa FAQ
- **"Twilight" style variation** — one-click moody evening mode with deep greens and candlelight gold
- **Photo-rich by default** — real spa photography wired into hero, treatments, gallery, team and booking patterns
- **Motion with manners** — soft scroll reveals and eased stat counters; all disabled under `prefers-reduced-motion`
- **Accessibility** — skip link, visible focus states, semantic landmarks, keyboard-friendly navigation
- **Translation-ready** — `serene` text domain

## Installation

1. Download or clone this repository.
2. Copy the `serene-spa-theme` folder into `wp-content/themes/` (rename the folder to `serene` if you like).
3. In WordPress, go to **Appearance → Themes** and activate **Serene**.
4. Open **Appearance → Editor** to customize templates, or insert any **Serene** pattern from the block inserter.

No plugins required. Google Fonts (Cormorant Garamond + Jost) load automatically; the theme works offline with system fallbacks.

## Customization

- **Colors & fonts:** everything flows from `theme.json` — tweak the palette, type scale or spacing there.
- **Style variation:** switch to the **Twilight** evening style from the Site Editor's Styles panel.
- **Custom page template:** `page-wide.html` is registered as a page template with a wider canvas.
- **Block styles:** Serene outline (button), Serene card (group), Serene soft corners (image), Serene pull quote (quote), Serene eyebrow (heading).
- **Front-end script:** `assets/js/theme.js` handles the back-to-top button, scroll reveals and stat counters — vanilla JS, no dependencies.
